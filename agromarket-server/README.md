# АгроМаркет API

Backend для «АгроМаркета» на Node.js + Express 5. Отдаёт каталог товаров и принимает оптовые заявки из React-формы.

## Запуск

```
npm install
npm run dev      # http://localhost:3000 (автоперезапуск через node --watch)
```

Frontend (`agromarket-react`) запускается отдельно: `npm run dev` → http://localhost:5173.
CORS разрешён только для этого адреса.

## Эндпоинты

| Метод | Путь              | Описание                          | Ответы   |
|-------|-------------------|-----------------------------------|----------|
| GET   | /api/health       | проверка сервера                  | 200      |
| GET   | /api/about        | информация о проекте              | 200      |
| GET   | /api/products     | товары, `?search=` `?maxPrice=` `?sort=` | 200 |
| GET   | /api/products/:id | один товар                        | 200, 404 |
| GET   | /api/orders       | список заявок                     | 200      |
| POST  | /api/orders       | новая заявка                      | 201, 400 |

### Параметры `GET /api/products`

| Параметр   | Пример                  | Что делает                                  |
|------------|-------------------------|---------------------------------------------|
| `search`   | `?search=мёд`           | товары, в названии которых есть строка (без учёта регистра) |
| `maxPrice` | `?maxPrice=1000`        | товары с ценой не выше указанной            |
| `sort`     | `?sort=price` / `?sort=-price` | по возрастанию / по убыванию цены    |

Параметры работают вместе: `/api/products?search=мёд&maxPrice=5000&sort=-price`.

### `POST /api/orders`

Тело запроса (JSON): `name`, `email`, `quantity` — обязательны; `phone`, `date`, `comment` — по желанию.

- `201` — заявка создана, в ответе объект заявки с `id`
- `400` — не хватает обязательных полей или `quantity` меньше 10 (`{ "error": "Минимальный объём заказа — 10 кг" }`)

Заявки хранятся в памяти и пропадают при перезапуске сервера.

## Лабораторная 5 — ответы

- **Content-Type у res.send и res.json:** у `/` (`res.send` со строкой) — `text/html; charset=utf-8`, у `/api/health` (`res.json`) — `application/json; charset=utf-8`. `res.json` сам сериализует объект и ставит нужный тип, поэтому клиент знает, что получил JSON.
- **Что происходит без next() в middleware:** страница «висит», ответ не приходит (curl завис до таймаута). Запрос остановился на логгере: он не передал управление дальше, а сам ответ не отправил, поэтому до маршрута дело не дошло.
- **Логгер после маршрутов:** запросы не логируются (в терминале только строка запуска). Express проходит цепочку сверху вниз. Подходящий маршрут отвечает и завершает цепочку, а для несуществующих адресов отвечает обработчик 404, поэтому до логгера в конце файла запрос не доходит. Порядок `app.use()` = порядок обработки.
- **Отправка формы без express.json():** пришёл статус 400 «Поля name, email и quantity обязательны». Без `express.json()` тело запроса не разбирается, `req.body` остаётся `undefined`, и сервер считает, что обязательных полей нет.
- **Использовал(а) ли ИИ и для чего:** да, ИИ (Claude) использовался для сборки каркаса проекта по заданию, бонусов (`maxPrice`, `sort`, `validateOrder`, состояние «Отправка…») и первого черновика README. Код запускал и проверял сам(а), ответы про эксперименты сверены с результатами запуска.

## Бонусы

- Сортировка `?sort=price` / `?sort=-price` (сортируется копия массива)
- `middleware/validateOrder.js` подключён на уровне маршрута: `router.post('/', validateOrder, ...)`
